Get the phone connected

Clears anything left over from last time, finds the address this PC is actually reachable on, writes it into the app, starts the sync server, and starts Expo pinned to that same address. Then scan the code.

Tunnel mode routes through the internet instead of the wifi. Slower to start and the sync server stays unreachable, but it works on networks that block phone-to-laptop traffic entirely.

Approved record — from documents

      
Reads the submittal PDFs and builds the approved record from
      them. A model reads the documents; server/ingest.mjs decides what
      is allowed to become an approved revision. Rows that are still
      PENDING, or that name a zone this project doesn't have, never make it in.

      

        
        

          
          
        

        

          
          
        

        
      

      
      
      

        Switching this changes what the engine considers approved, so restart the
        app afterwards. On the ingested record, parts whose submittal was held for
        review correctly answer NO APPROVED RECORD instead of a confident
        answer nobody signed off.

Build the phone app (APK)

      
An APK installs directly on a phone with no Expo Go and no
      Metro — which is what you want for filming the offline sequence, because
      Expo Go streams its bundle over wifi and can drop mid-take.
      Save your connection settings first: the server address is baked in
      at build time.
